# Linked-List-Collection

This project demonstrates a "perfect" template linked list collection, involving many Abstract Data Type (ADT) operations, such as list, stack, and queue operations. The collection includes STL libraries, basic exception handling, and copying and moving semantics. To test the collection, first create a .cpp executable, then test every function in the header file. It is recommended print the vector after each function call, and it is optional to document the compute time of the sorting and searching functions to demonstrate time complexity of different algorithms.

Note (1): This collection does include duplicate values. To disallow this, add duplicate checks in the insertion operations before inserting values.
